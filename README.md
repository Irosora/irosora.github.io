# irosora.github.io

Personal site of Max Ham, Lead Machine Learning Engineer in Toronto, served by GitHub Pages at <https://irosora.github.io/>.

Hand-written static HTML, CSS, and a little vanilla JavaScript. There is no build step: GitHub Pages serves the files as they are.

| File | Purpose |
| --- | --- |
| `index.html` | The site |
| `styles.css`, `script.js` | Shared styles and the theme toggle |
| `404.html` | Not-found page |
| `Max_Ham_Resume.pdf` | Resume download linked from the site |
| `privacy.html` | Privacy policy for Workbench Personal, a personal productivity tool used only by its owner |
| `og-image.png`, `favicon.*`, `apple-touch-icon.png`, `icon-*.png`, `site.webmanifest` | Sharing image and icons |
| `robots.txt`, `sitemap.xml` | Crawler hints |

Preview locally with `python3 -m http.server 8000` from this folder, then open <http://localhost:8000/>.
